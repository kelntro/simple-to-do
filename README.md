# 📝 Simple To-Do App

A minimal full-stack to-do list app built with React (frontend), Node.js + Express (backend), and PostgreSQL (database).

## 🚀 Features

- Add tasks
- View all tasks
- Delete tasks
- Persistent data with PostgreSQL
- Deployed via Render

---

## 🛠️ Tech Stack

- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Deployment:** Render
